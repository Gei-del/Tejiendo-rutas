# Tejiendo-rutas
# 🧵 Tejiendo Rutas  Juego de puzles y plataformas donde conectas una ciudad mediante hilos que representan energía, datos y colaboración.  ## 🎮 Mecánicas - Conectar nodos usando hilos - Optimizar recursos (economía) - Restaurar color y vida a la ciudad  ## 🧠 Concepto Inspirado en cómo la tecnología y la economía construyen redes urbanas.
